# CDC PLACES Health Dashboard

## Project Overview

This project aims to develop an interactive dashboard using CDC PLACES county-level data to explore and compare community health indicators across the United States.

The dashboard will focus on three health indicators:
- Diabetes
- Obesity
- Lack of health insurance

Users will be able to filter by state and county, compare health indicators, and explore differences in estimated chronic disease burdens across communities.

## Data Source

CDC PLACES: Local Data for Better Health, County Data, 2025 Release.

Dataset: https://data.cdc.gov/500-Cities-Places/PLACES-Local-Data-for-Better-Health-County-Data-20/swc5-untb
